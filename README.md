# 通讯录

命令行通讯录，支持增删查和自动存盘。数据保存在纯文本文件里。

## 依赖

- gcc
- make

## 编译和运行（windows平台）

```
make        # 编译，产物在 build/
make run    # 编译并运行
make clean  # 删掉 build/
```

## 用法

启动后按菜单选数字：

| 输入 | 功能 |
|------|------|
| 1 | 添加联系人 |
| 2 | 删除联系人 |
| 3 | 按姓名查找 |
| 4 | 列出全部 |
| 0 | 保存并退出 |

数据存在当前目录的 `contacts.txt`，退出时自动保存。

## 目录结构

```
src/       源文件
include/   头文件
build/     构建产物，不进仓库
```

| 模块 | 职责 |
|------|------|
| `main.c` | 菜单循环和分派 |
| `contact.c` | 联系人增删查 |
| `storage.c` | 存盘和读盘 |
| `ui.c` | 打印和读输入 |

## 已知限制

- 最多 100 个联系人（上限见 `include/contact.h` 的 `MAX_CONTACTS`）
- 电话不能修改
- 姓名和电话不能含空格（用空格作分隔符存储）
- 不支持重名
